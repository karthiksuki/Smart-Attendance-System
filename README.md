# REAL-TIME ATTENDANCE MONITORING SYSTEM 

## Objective:
Develop an automated, real-time attendance tracking system using facial recognition to improve accuracy, efficiency, and eliminate manual data entry.

## Process:

- Captured images of students using OpenCV, taking 30 pictures per student when the attendance button is pressed.
- Used the Haar Cascade Classifier model for facial recognition to detect and identify students based on their facial features.
- Automatically matched the detected faces to a pre-existing database of student roll numbers and names.
- Logged the attendance data (student roll number, name, and timestamp) into an Excel sheet for accurate record-keeping.
- Integrated an automated email system to send real-time attendance updates to relevant authorities or staff.

## Outcome:

- Eliminated manual attendance recording, reducing human error and saving time.
- Ensured accurate, real-time attendance tracking for classrooms or events.
- Provided a streamlined and automated process for managing student attendance, with reports instantly available in Excel and delivered via email.
